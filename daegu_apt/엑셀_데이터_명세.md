# 대구 아파트 부동산 데이터 명세 & LLM 추천 가이드

이 문서는 **두 가지 역할**을 합니다.
1. 동봉된 엑셀(`{지역}_부동산_*.xlsx`, `대구전체_부동산_*.xlsx`)의 **데이터 명세**.
2. 이 문서를 읽은 **LLM이 사용자에게 질문하고 답을 받아(여러 차례) 최적의 아파트 단지를 추천**하기 위한 지침.

---

## 0. LLM 사용 지침 (이 문서를 읽은 AI에게)

당신은 이 명세와 동봉 엑셀만으로 대구 아파트 추천을 돕는 도우미입니다. 다음을 지키세요.

1. **먼저 충분히 질문하라.** 사용자의 조건을 한 번에 다 받지 말고, 핵심부터 단계적으로 물어 좁혀라(§5 절차 참고). 답이 모호하면 다시 물어라.
2. **추천 단위는 (단지 + 평형) 쌍이다.** 호가_단지요약은 단지×평형 1행 구조다. 같은 단지라도 25평과 45평은 가격·면적·실거래가 모두 다른 **별개의 추천 후보**다. 단지 기준으로 묶어 1개만 추천하지 말고, 각 (단지, 평형) 행에 독립적으로 점수를 매겨 추천 여부를 결정하라.
3. **추천 근거를 컬럼 값으로 제시하라.** "왜 이 단지·평형인지"를 데이터 컬럼 값으로 설명하라.
3. **§1 주의사항을 반드시 반영하라.** 특히 학교·거리·호가의 한계를 사용자에게 분명히 고지하고, 데이터로 단정하지 마라.
4. **데이터에 없는 것은 추측하지 말고, 사용자가 직접 확인하도록 안내하라** (예: 정확한 학교 배정, 실제 도보시간, 현재 매물 유무).
5. **추천의 1차 근거는 항상 엑셀 데이터**(호가_단지요약·매물상세·실거래가)다.
6. **웹 검색은 보조 수단으로 활용하라.** 사용자가 요청하거나 추천 품질 향상에 도움이 되는 경우, 엑셀에 없는 정보(최근 실거래 동향, 개발·교통 호재, 학군·교육 환경, 상권·생활 인프라, 입주 예정 물량, 지역 선호도·시장 분위기 등)를 웹에서 조사해 반영할 수 있다. 엑셀만으로 답하기 어려운 질문에는 "웹 검색으로 최신 정보를 함께 확인해드릴 수 있다"고 먼저 안내하라.
7. **출처를 구분해 설명하라.** 어떤 내용이 엑셀 기반이고 어떤 내용이 웹 검색 기반인지 명시하라. 두 정보가 충돌하면, 엑셀은 수집 시점 스냅샷이고 웹 정보가 더 최신일 수 있음을 설명하라.
8. **이 문서를 다 읽으면** 첨부된 `{지역}_부동산_{YYYYMMDD}_{HHMMSS}.xlsx`를 읽은 뒤 바로 사용자에게 질문을 시작하라.

## 1. ★★ 반드시 알아야 할 주의사항 (추천 전 필수 반영) ★★

### ★ 학교: "가장 가까운" 학교일 뿐, **배정(학군) 학교가 아니다**
- `근처초등학교/중학교/고등학교`는 단지 좌표에서 **직선거리상 가장 가까운** 학교를 카카오 지도에서 찾은 것이다.
- **초등학교는 거주지 주소에 따라 배정(학군)된다. 바로 옆에 학교가 있어도 그 학교로 배정되지 않을 수 있고, 더 멀리 배정될 수도 있다.**
- 따라서 이 컬럼으로 "이 단지는 OO초 배정"이라고 **단정하면 안 된다.** 참고용 거리 지표로만 쓰고, 실제 배정은 **거주지 주소 기준으로 관할 교육청·학교군 또는 네이버 부동산 단지정보에서 사용자가 직접 확인**하도록 안내하라.
- 중·고등학교도 동일하게 "가장 가까운"일 뿐 배정/선택과 다를 수 있다.

### ★ 모든 거리·도보(분)는 **직선거리 추정치**다
- `지하철직선도보(분)`, `OO학교직선거리(m/분)`, 마트·공원·어린이집의 `(m/분)`는 모두
  **직선거리(haversine) ÷ 도보속도 67m/분(4km/h)** 으로 계산했다.
- 실제 도로·횡단보도를 우회하는 도보시간은 **이 값보다 길다.** 길찾기(경로) 기반이 아니다. 상대 비교용으로만 사용하라.

### ★ 호가 ≠ 실거래가
- `호가_단지요약`·`매물상세`의 가격은 **매도자 희망가(호가)**다. 실제 체결가와 다르며 보통 호가가 높다.
- 실제 체결 수준은 `실거래가` 시트(국토교통부 확정 거래)를 함께 보라.

### ★ "(참고)" 컬럼은 신뢰도 낮음
- `중개사명(참고)`·`중개사_코멘트(참고)`·`태그(참고)`는 비정형·중개사별 편차가 큰 보조 정보다. 추천 판단에는 **가중치 0**(거의 반영하지 않음)으로만 쓰라.

### ★ 수집 시점 스냅샷
- 매물(호가)은 수시로 변한다. 파일명의 날짜·시각 기준이며, 추천 시 "수집 시점 기준"임을 고지하라. 매물수 0인 단지도 단지 정보는 포함되어 있다(현재 호가 매물 없음).

## 2. 파일 종류

| 파일명 패턴 | 내용 |
|------------|------|
| `{구}_부동산_{YYYYMMDD}_{HHMMSS}.xlsx` | 구별 — 호가요약 + 매물상세 + 실거래가 |
| `대구전체_부동산_{YYYYMMDD}_{HHMMSS}.xlsx` | 8개 구 통합본 (구간 단지 중복 없음) |
| `{구}_실거래가_*.xlsx` | 실거래가만 단독 (main_molit.py) |

데이터 출처: 호가·단지정보=네이버 부동산, 위치(지하철·학교·마트·공원·어린이집)=카카오 Local API, 실거래가=국토교통부.
단지는 네이버 법정동(cortarNo) 단위로 수집되어 각 단지가 정확히 한 구에 귀속된다.

## 3. 시트 1: 호가_단지요약  (추천의 메인 데이터)

단지×전용평형 1행. 같은 단지라도 평형이 다르면 별도 행.

| 컬럼 | 설명 / 추천 활용 |
|------|------|
| 지역(구) | 자치구 (예: 수성구). 지역 선호 필터 |
| 지역(동) | 법정동 (예: 범어동) |
| 단지명 | 아파트 단지명 |
| 건축년월 | 준공 연월(YYYYMM). 신축/구축 선호 필터 |
| 총세대수 | 단지 규모. 대단지 선호 시 필터 |
| 전용평형(평) | 이 행의 전용면적 평형. 가구 인원/희망 평형 필터 |
| 매매_최저/최고/평균(만원) | 현재 매매 호가 범위·평균. 예산 필터의 핵심 |
| 매매_매물수 | 매매 호가 매물 수(매물상세 행수와 일치). 0이면 현재 매매 매물 없음 |
| 전세_최저/최고/평균(만원) | 현재 전세 호가 범위·평균 |
| 전세_매물수 | 전세 매물 수 |
| 월세_매물수 | 월세 매물 수 |
| 5억이하매물수(호가) | 매매 호가 5억 이하 & 전용 85㎡ 이하 매물 수 (생애최초/대출 관점 참고) |
| 단지코드 | 네이버 단지 식별 코드 |
| 위도 / 경도 | 단지 좌표(WGS84) |
| 근처지하철 | 가장 가까운 지하철역명 (반경 3km) |
| 지하철직선도보(분) | 그 역까지 ★직선거리÷67m/분 추정. 교통 접근성 비교 |
| 근처초등학교 | 가장 가까운 초등학교명 (★배정 아님, §1 참고) |
| 초등학교직선거리(m/분) | ★직선거리(m)/직선도보(분) |
| 근처중학교 | 가장 가까운 중학교명 (★배정/선택 아님) |
| 중학교직선거리(m/분) | ★직선거리(m)/직선도보(분) |
| 근처고등학교 | 가장 가까운 고등학교명 (★배정/선택 아님) |
| 고등학교직선거리(m/분) | ★직선거리(m)/직선도보(분) |
| 인근대형마트(5km) | 반경 5km 대형마트 목록 (이마트(2200m/33분) 형식, ★직선) |
| 인근공원(1km) | 반경 1km 공원 목록 (★직선) |
| 인근어린이집(1km) | 반경 1km 어린이집 목록 (★직선). 영유아 자녀 참고 |
| 회전률(N개월%) | 최근 N개월 실거래건수÷총세대수×100. 거래 활발도(환금성) 참고. ★아래 주의사항 참고 |
| 분양권거래수(N개월) | 분양권·입주권 거래건수 (분양권 API 승인 시). 회전률 과대평가 가능성 있을 때 함께 확인 |
| ⚠️회전율주의 | "분양권포함-회전율과대평가주의" — 신축 분양 단지에서 분양권 전매가 회전률에 포함되어 실제보다 높게 나올 수 있음 |

**갭(전세낀매매)**: 매매_최저 − 전세_최고 ≈ 필요 자기자본(갭). 갭투자 관심 시 작은 단지부터.

## 4. 시트 2: 매물상세 / 시트 3: 실거래가

### 매물상세 (개별 호가 매물, 전 페이지 완전 수집)
지역 · 단지명 · 단지코드 · 거래유형(매매/전세/월세) · 가격(만원) · 공급평형 · 전용평형 · 전용률(%) · 공급면적㎡ · 전용면적㎡ · 층 · 방향 · 등록일 · 매물번호 · 동일매물수(동일물건 등록 중개사 수) · 동일_최저가/최고가(만원) · **중개사명(참고) · 중개사_코멘트(참고) · 태그(참고)** (★낮은 신뢰도)
- 호가_단지요약의 `매매_매물수` = 매물상세 동일 단지×평형 매매 행수 (항상 일치).

### 실거래가 (국토교통부 확정 거래, molit 키 있을 때만)
지역 · 구 · 법정동 · 도로명 · 아파트명 · 동 · 건축년도 · 전용면적㎡ · 층 · 거래금액(만원) · 거래유형(중개/직거래) · 매수자/매도자 · 거래년/월/일 · 등기일자 · 해제여부(O=취소) · 해제사유발생일
- `해제여부=O`는 취소된 거래이니 통계에서 제외하고 보라. 호가의 현실성 검증에 사용.

**★ 호가↔실거래가 평형 매칭 규칙 (반드시 준수)**
- 실거래가의 `전용면적㎡`를 평으로 환산: `평 = 전용면적㎡ × 0.3025` (소수 첫째 자리 반올림)
- 호가_단지요약의 `전용평형(평)`과 비교 시 **±2평 이내인 행만** 같은 평형으로 간주한다.
- 예: 호가 25평 → 실거래가 전용면적 79~86㎡(23~26평) 행만 비교 대상. 45평짜리 실거래 데이터와 섞으면 안 됨.
- 단지 내 평형이 여럿이면(예: 25평·32평·45평) **평형별로 독립적으로** 실거래 가격을 집계해 각 평형 호가와 대조하라.

## 5. LLM 추천 절차 (이 순서로 사용자와 문답하라)

**STEP 1 — 핵심 조건부터 (한두 개씩 질문)**
- 예산 상한(만원)? (매매_평균/최저)
- 희망 지역: 특정 구·동 선호 또는 "상관없음"?
- 가구/평형: 인원수 또는 희망 전용평형대?

**STEP 2 — 생활 우선순위 (가중치 파악)**
- 자녀 학령? (영유아→어린이집, 초등→초등 거리 *단 배정 주의 고지*, 중·고→해당 거리)
- 지하철 접근성 중요도? (지하철직선도보 분)
- 신축 선호? (건축년월) / 대단지 선호? (총세대수)
- 마트·공원 등 생활 인프라 중요도?
- (투자라면) 갭·회전률 중시?

**STEP 3 — 데이터 매핑·필터링**

> **★ 필터링·점수 산정의 기본 단위는 호가_단지요약의 각 행(단지×평형 쌍)이다.**  
> 같은 단지의 25평 행과 45평 행은 별개 후보로 독립 평가한다. 단지 단위로 먼저 묶고 대표 평형 하나만 고르는 방식은 쓰지 말 것.

| 사용자 답 | 사용할 컬럼 | 방법 |
|---|---|---|
| 예산 | 매매_평균/최저 또는 전세_* | 상한 이하 필터 (행별 독립 적용) |
| 지역 | 지역(구)/지역(동) | 일치 필터 |
| 평형 | 전용평형(평) | 범위 필터 (이 필터를 통과한 행만 후보) |
| 지하철 중요 | 지하철직선도보(분) | 오름차순 정렬·가중 |
| 학령(초등) | 초등학교직선거리(m/분) | 참고 정렬 + ★배정 별도확인 고지 |
| 신축 | 건축년월 | 최근일수록 가점 |
| 대단지 | 총세대수 | 큰 값 가점 |
| 환금성/투자 | 회전률, 매매_매물수, 갭 | 보조 지표 |
| 실거래가 교차 검증 | 아파트명 + 전용면적㎡→평 환산 | **★ 반드시 동일 평형끼리만** 비교. 실거래가의 `전용면적㎡ × 0.3025`를 평으로 변환해 호가 `전용평형(평)`과 ±2평 이내인 행만 사용. 다른 평형 데이터를 섞지 말 것 |

**STEP 4 — 추천 제시**
- 조건에 맞는 후보를 좁혀 **5~10개 (단지, 평형) 쌍** 을 점수순으로 제시.
- **단지가 같아도 평형이 다르면 별개 항목으로 나열한다.** 예: "래미안수성1 25평 / 래미안수성1 32평"은 2개 후보.
- 각 후보를 `단지명 (전용평형평) — 이유` 형식으로 표시하면 혼동을 줄일 수 있다.
- 각 후보의 트레이드오프를 설명(예: "A 25평은 지하철 5분이지만 구축, A 32평은 같은 단지지만 예산 초과").
- ★주의 고지: 학교 배정·실제 도보·호가 vs 실거래는 사용자가 직접 확인하도록 안내.
- **★ 호가↔실거래가 비교는 반드시 동일 평형끼리만.** "이 단지 25평 호가 3억 / 최근 실거래 2.8억" 식으로 제시할 때, 실거래가 데이터를 `전용면적㎡ × 0.3025`로 평 환산해 해당 평형과 ±2평 이내인 거래만 인용하라. 다른 평형 실거래가를 같이 섞으면 비교 자체가 무의미해짐.
- 후보가 너무 많거나 적으면 STEP 1~2로 돌아가 조건을 조정.

## 6. 데이터 한계 요약
- 호가는 희망가(실거래와 상이) · 학교는 최단(배정 아님) · 거리는 직선 추정 · "(참고)" 컬럼 저신뢰 · 수집 시점 스냅샷.
- 좌표 오류로 일부 단지 위치 정보가 부정확할 수 있음.
- 회전률·실거래가는 국토부 API 키 있을 때만 채워짐.
- **회전률 주의사항**: Naver 단지명 ↔ 국토부 아파트명 매핑 기반으로 집계. 대구 전체 기준 실거래 단지의 약 91%가 매핑됨. 나머지 ~9%는 ①노후단지(Naver 매물 없음) ②국토부가 동(棟) 단위로 쪼개어 등록한 단지(동촌미소타운101동·캐슬골드파크1단지 등)로, 해당 거래는 회전률에 미반영. 따라서 회전률 0%가 거래 없음을 의미하지 않을 수 있음 — 참고 지표로만 활용.
- **분양권 주의**: ⚠️회전율주의 표시 단지는 분양권 전매 거래가 회전률에 합산되어 실제 아파트 매매 회전률보다 높게 나올 수 있음.
