============================================================
  대구 아파트 부동산 수집기 — 사용설명서
============================================================

네이버 부동산 호가, 국토교통부 실거래가, 카카오 위치정보(지하철·학교·
마트 등)를 모아 엑셀 파일로 저장하는 프로그램입니다.


────────────────────────────────────────────
1. 실행 방법
────────────────────────────────────────────

  daegu_apt_gui.exe  를 더블클릭하세요.

  ※ exe 파일과 옆에 있는 _internal 폴더는 한 세트입니다.
    옮길 때 폴더째로 함께 옮기세요. (_internal 없으면 실행 안 됨)


────────────────────────────────────────────
2. API 키 설정 (처음 한 번만)
────────────────────────────────────────────

프로그램 왼쪽 패널에 키 두 개를 넣고 [저장]을 누르면 됩니다.
저장하면 다음 실행부터 자동으로 불러옵니다.

  ▶ 카카오 API 키   ← 위치정보(지하철·학교·마트·공원) 수집에 필요 (필수)
      발급: https://developers.kakao.com
        1) 로그인 → [내 애플리케이션] → 애플리케이션 추가
        2) [요약 정보]의 "REST API 키" 복사
        3) [카카오 로그인] 말고, [앱 설정 > 앱 키]의 REST API 키 사용
        ※ [카카오 로컬] 기능이 ON 인지 확인 (보통 기본 ON)

  ▶ 국토부 API 키   ← 실거래가 수집에 필요 (선택, 없으면 호가만 수집)
      발급: https://www.data.go.kr
        1) 회원가입 → "아파트 매매 실거래가 상세 자료" 검색
        2) [활용신청] (무료, 보통 즉시 승인)
        3) 마이페이지 > 일반 인증키(Encoding 또는 Decoding) 복사

  👁 버튼으로 입력한 키를 확인할 수 있습니다.


────────────────────────────────────────────
3. 수집하기
────────────────────────────────────────────

  1) 수집할 구를 체크박스로 선택 (여러 개 선택 가능)
     - [전체 선택] 버튼으로 8개 구 한 번에 선택
  2) 데이터 소스 선택
     - 호가+실거래 / 호가만 / 실거래만
  3) [▶ 수집 시작] 클릭
  4) 오른쪽 로그 창에서 진행 상황 확인
  5) 끝나면 [파일 열기]로 결과 확인

  ※ 구를 여러 개 선택하면 2개씩 동시에 수집해 시간을 줄입니다.
  ※ 저장 폴더를 비워두면 프로그램 폴더에 저장됩니다.


────────────────────────────────────────────
4. 결과 파일
────────────────────────────────────────────

  • {구}_부동산_날짜_시간.xlsx   ← 구별 개별 파일
  • 대구통합_부동산_날짜_시간.xlsx ← 여러 구를 한 파일로 합친 통합본
                                  (2개 이상 선택 시 자동 생성)

  각 파일의 시트:
  • 호가_단지요약 : 단지×평형별 매매/전세/월세 시세 + 위치정보
                   - 지하철 도보시간, 초·중·고등학교 직선거리
                   - 인근 대형마트·공원·어린이집
                   - 12개월 회전률 (국토부 키 있을 때만)
                   (현재 매물이 없는 단지도 단지 정보는 포함)
  • 매물상세     : 개별 매물 목록 (가격·층·면적·중개사 참고정보)
  • 실거래가     : 국토교통부 아파트 매매 확정 거래 (국토부 키 있을 때만)
  • 분양권실거래  : 국토교통부 분양권·입주권 거래 (국토부 키 + API 별도 승인 시)

  ※ 학교는 "가장 가까운" 학교이며, 실제 배정 학교와 다를 수 있습니다.
     실제 배정은 교육청이나 네이버 단지정보에서 확인하세요.


────────────────────────────────────────────
5. 예상 소요 시간
────────────────────────────────────────────

  작은 구(서구·중구·남구)     : 약 4~6분
  큰 구(수성구·달서구·동구)   : 약 15~20분
  대구 전체 8개 구           : 약 40분 (2개씩 동시 수집 기준)


────────────────────────────────────────────
6. 잘 안 될 때
────────────────────────────────────────────

  • 위치정보(지하철·학교)가 비어 있어요
    → 카카오 API 키를 확인하세요. [저장] 후 다시 실행.

  • 실거래가 시트가 없어요
    → 국토부 API 키가 없거나 틀렸습니다. (호가는 키 없이도 수집됩니다)

  • "수집된 데이터가 없습니다"
    → 인터넷 연결 또는 키를 확인하고 잠시 후 다시 시도하세요.

  • 실행이 안 돼요
    → _internal 폴더가 exe와 같은 위치에 있는지 확인하세요.
